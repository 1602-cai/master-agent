| 页码 | 标题 | 节奏类型 | 说明 |

## Forbidden (禁止事项)

| 类别 | 禁止内容 |
|------|----------|
| 🚫 **图片** | 内页 (P2-P5) 禁止使用任何装饰性图片或插图 |
| 🚫 **图标风格** | 禁止使用填充型图标 (如 `tabler-filled`)、emoji、手绘风格图标 |
| 🚫 **字体** | 禁止使用衬线字体 (如 Times New Roman、宋体)、艺术字体、手写字体 |
| 🚫 **配色** | 禁止使用荧光色、高饱和纯色(如纯红`#FF0000`)、渐变彩虹色 |
| 🚫 **装饰元素** | 禁止使用3D效果、阴影过重、发光效果、大面积渐变 |
| 🚫 **动画** | 禁止使用炫酷动画、声音效果、过度转场 |
| 🚫 **布局** | 禁止使用非标准画布尺寸 (如4:3、A4竖版) |
| 🚫 **数据呈现** | 禁止使用饼图 (对比不直观)；禁止使用3D图表 |
| 🚫 **文字规范** | 禁止正文全部大写；禁止行距小于1.2倍；禁止不换行导致文字溢出 |
