### P2 — 核心机制详解 (Content)

| 项目 | 内容 |

| **模板** | 内容页 (`002_content`) |

#### 2.1 NGSI v2 三层数据模型
- **Entity** (实体) → **Attribute** (属性) → **Metadata** (元数据)
- 从粗粒度到细粒度的层级结构，支撑按需披露

#### 2.2 三种渐进披露实现机制

| 机制 | 核心参数/方式 | 说明 |
|------|-------------|------|
| **① 查询筛选** | `attrs` / `q` 参数 | 客户端请求时指定所需属性和过滤条件，仅返回匹配数据 |
| **② 订阅通知** | `throttling` / 条件触发 | 设置速率限制和触发条件，按需推送变更通知 |
| **③ 属性级控制** | 属性级别权限/可见性 | 不同租户/用户可见不同属性集合，实现细粒度数据隔离 |

#### 2.3 典型数据流图示意
- 客户端 → NGSI v2 API → Orion Context Broker → 数据模型 (Entity/Attribute/Metadata) → 返回过滤后数据
- 订阅流程：客户端订阅 → Broker 监控 → 条件触发 → 通知推送

#### 2.4 6大测试重点维度
1. 属性级过滤准确性
2. 条件查询响应时间
3. 订阅触发正确性
4. 多租户数据隔离
5. 大规模实体性能
6. 并发场景稳定性

#### 2.5 性能基准参考
| 实体规模 | 预期参考 |
|---------|---------|
| 1K | 毫秒级响应 |
| 10K | 亚秒级响应 |
| 100K | 1-2秒级响应 |
| 1M | 需优化方案 |

**设计要点**：浅色背景，信息分栏/卡片布局；左侧展示数据模型层级图，右侧列表三种机制；底部或右侧放置性能参考表；使用强调色高亮关键数字和机制名称。

### P3 — 总结与展望 (Ending)

| 项目 | 内容 |
|------|------|
| **模板** | 结尾页 (`015_ending`) |
| **节奏** | anchor |
| **主标题** | 总结与展望 |
| **内容要点** | |

#### 3.1 应用场景回顾
- **智慧城市交通监控** — 不同部门看到不同上下文
- **工业 IoT 设备监控** — 按需聚合设备数据
- **智能农业** — 多租户环境下的数据分级披露

#### 3.2 测试策略总览
- 4 个标准测试用例：基础筛选 → 条件过滤 → 订阅触发 → 大规模性能
- 覆盖功能正确性与非功能性能

#### 3.3 未来展望
- **NGSI-LD** 语义化披露（Linked Data 增强）
- **KeyRock** 权限集成（统一身份认证）
- **分布式联合查询**（跨实例数据聚合）

#### 3.4 三大挑战
1. ⚡ **性能** — 大规模实体下的查询效率
2. 📐 **语义** — 上下文信息的标准化描述
3. 🔄 **实时性** — 高频率更新下的及时推送

**设计要点**：采用深色背景与封面呼应（如使用模板自带颜色）；三列/三块布局分别展示"已实现→测试中→展望"的递进关系；底部或侧边给出致谢语或联系方式。

## 9. 样式与细节规范

| 项目 | 规范 |
|------|------|
| **圆角** | 卡片/容器使用 8px 圆角 |
| **阴影** | 卡片使用轻量阴影 (box-shadow: 0 2px 8px rgba(0,0,0,0.06)) |
| **分隔线** | 使用 1px 实线，颜色 `#E2E8F0` |
| **数据表格** | 表头使用主色背景白色文字，表体交替行背景 |
| **箭头/流向** | 使用强调色 `#00A3C4`，描边宽度 2px |
| **列表符号** | 使用强调色小圆点或 tabler-outline 图标 |
| **对齐方式** | 标题左对齐，正文左对齐，数据居中对齐 |

## 10. 禁止项 (Forbidden)

- ❌ 不使用非技术性照片/图片
- ❌ 不使用过于鲜艳跳跃的颜色（如荧光色、高饱和红/紫）
- ❌ 不使用衬线字体（如 Times New Roman、宋体）
- ❌ 不使用厚重冗余的阴影或渐变
- ❌ 不添加动画/转场特效（静态演示优先）
- ❌ 不使用复杂的背景纹理或图案
- ❌ 不添加与核心机制无关的装饰元素
- ❌ 每页信息不超载（P2 密集但保持清晰分区）
