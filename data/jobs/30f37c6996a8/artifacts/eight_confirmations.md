### 八项确认建议（立即回应）

尊敬的客户，根据您提供的 **《锐明技术_盈利质量分析演讲稿》** 源文件、“**5页以内**”的页数限制，以及所选的“**`_9_极简风` (mirror模式)**”模板，我为您整合了以下八项专业建议。请审阅并确认，确认后我将立即输出完整的设计方案。

#### a. Canvas Format 画布格式
- **推荐格式**：**16:9 宽屏** (标准PPT比例)
- **原因**：这是目前最通用的演示标准，适合大多数投影设备和屏幕，视觉上更加现代、开阔，非常适合财务分析和商务汇报场景。

#### b. Page Count 页数建议
- **建议页数**：**5页**
- **具体规划**：
    1.  **封面页** (1页)
    2.  **目录/大纲页** (1页，可选，可合并至封面后或作为内容页首部分)
    3.  **核心内容页** (3页，如：盈利现状分析、核心指标解读、问题与建议)
- **注意**：源文件内容是一篇演讲稿，结构上更偏向叙事。受5页限制，每一页将承载一个完整的核心观点段落，而非传统的数据罗列。

#### c. Key Information 关键信息确认
- **目标受众**：企业管理者、投资者、金融分析师或公司内部决策层。
- **使用场合**：内部经营分析会、季度/年度财务汇报、或面向投资人的路演。
- **核心信息**：**锐明技术的盈利质量现状、关键指标变化趋势及其背后的业务动因**。
- **初步判断**：这是一份典型的**财务分析类商务汇报**，逻辑性强，以数据为支撑，旨在通过分析发现问题和机会。

#### d. Style Objective 风格目标
- **d. Style: B) 通用咨询 + 极简商务风**
- **分析**：
    - **Layer 1 (模式)**: 您的源文档包含大量数据分析（营收增长、毛利率变化、现金流等），属于严谨的财务汇报，**B) 通用咨询 (General Consulting)** 模式最合适。此模式强调 **“让数据说话”**，追求清晰、专业的视觉呈现，不喧宾夺主。
    - **Layer 2 (视觉风格)**: 配合您选择的 **“`_9_极简风`”** 模板，最终风格融合为 **“极简商务风”**。它将模板的干净、留白、克制感，与商务需求的严谨、数据清晰度相结合。

#### e. Color Scheme 配色方案
- **推荐配色方案（源文档无指定颜色，模板本身提供了基础色）：**
    - **主色 (60%)**: `#1A365D` (深邃靛蓝) - 代表科技、专业与信赖感。
    - **辅色 (30%)**: `#FFFFFF` & `#F7FAFC` (白及极浅灰) - 保持极简感，增加层次。
    - **强调色 (10%)**: `#E53E3E` (警示红) - 用于标注重点数据（如负增长、现金流问题），形成视觉焦点。
    - **文字色**: `#2D3748` (深灰铅色)，确保高对比度 (>4.5:1)。
- **注意**：如果您有公司标准色，请提供，我们会优先采用。

#### f. Icon Usage 图标使用
- **推荐方案**：**C) 内置图标库 (Built-in Icon Library)**
- **推荐库名**：**tabler-outline**
- **原因**：`tabler-outline` 图标风格是纤细的线性描边，与“极简商务风”高度契合，不会抢夺文字和数据的主视觉权重，显得精致且专业。
- **确认需求**：请确认使用 `tabler-outline` 作为本PPT的唯一图标库。

#### g. Typography Plan 字体方案
- **推荐组合（中西文对比搭配）**：
    - **中文标题**: `“思源黑体 Bold”` (Source Han Sans SC Bold) → 西文后备: `“Segoe UI Bold”`
    - **中文正文**: `“微软雅黑” (Microsoft YaHei)` → 西文后备: `“Segoe UI”`
- **原因**：黑体字族（无衬线）清晰、现代，非常适合商务演示。标题用粗体产生力量感和层级，正文用常规体保证可读性。`Segoe UI` 是 Windows 预装字体，保证兼容性。
- **字号参考**：标题 28-36pt，正文 14-18pt，数据标注 12-14pt。

#### h. Image Usage 图片使用
- **推荐方案**：**不使用实景图片，严格遵循极简风**
- **原因**：财务报表分析不适宜加入与内容无关的“装饰性”图片（如会议、计算机等），这可能会拉低专业度。建议完全依赖模板的几何图形（线条、形状、色块）和精心设计的数据图表来构建视觉层次。封面页可使用一个与“数据流”或“趋势”相关的抽象极简图形，或直接使用纯色+大号标题。
